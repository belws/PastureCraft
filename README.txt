PastureCraft
============

An empty Forge mod foundation.
Mod ID: pasturecraft
Java package: com.pasturecraft
Minecraft: 1.20.1
Forge: 47.4.10
Java: 17

The mod entrypoint contains no gameplay content or event handlers.
Import build.gradle as a Gradle project in your IDE.

The included LICENSE.txt and CREDITS.txt retain the upstream Forge notices.
Mod license metadata is configured separately in gradle.properties.

The project uses Mojang's official mappings. Mapping license information:
https://github.com/MinecraftForge/MCPConfig/blob/master/Mojang.md
